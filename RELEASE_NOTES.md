# Virtual Camera Android Root 2.0.20

This release provides downloadable builds of **Virtual Camera Android Root** for supported Android ABIs.

## Download the correct APK

- **arm64-v8a** — primary build for most modern ARM-based Android smartphones.
- **armeabi-v7a** — build for compatible 32-bit ARM devices.
- **x86_64** — build for supported Android environments with x86_64 processors.

## About the app

Virtual Camera Android Root is designed to use prerecorded gallery videos as a virtual camera feed on supported rooted Android devices using LSPosed. Its targeted functionality includes original media audio routing, microphone management, continuous video loops, orientation handling, and application-specific camera integration.

## Requirements

- A device with the matching ABI and Android version supported by the actual APK manifest.
- Compatible Android root and LSPosed installation.
- Camera/audio behavior depends on the target app, device and software versions.
